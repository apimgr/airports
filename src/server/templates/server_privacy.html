Privacy

The Airports API is a public, read-only reference service. There are no user accounts, no logins, and no tracking cookies.

What we collect

  • Request logs — standard HTTP access logs (timestamp, method, path, status, response size, user agent) retained only as long as the operator's log rotation policy dictates.
  • Caller IP for GeoIP lookup — used at request time only to surface nearby airports on the home page. The IP is never persisted, never logged in association with results, and never shared with third parties.

What we do NOT collect

  • No user accounts, no email addresses, no profile data.
  • No cookies for tracking. Theme preference is stored in localStorage on the browser only.
  • No third-party analytics, no ad networks, no tag managers.

Third-party services

GeoIP databases are downloaded from public CDNs at server startup and refreshed weekly. No request data is sent to any third party at runtime.
