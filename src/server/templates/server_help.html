Help & API Reference

The Airports API is a public, read-only REST + GraphQL service. No authentication, no API keys, no rate-limited tiers — every endpoint is free for everyone.

Quick start

# Get a single airport by ICAO or IATA code
curl -q -LSsf https://YOUR_SERVER/api/v1/airport/KJFK

# Search by name, city, country, or code
curl -q -LSsf "https://YOUR_SERVER/api/v1/search?q=denver"

# Find airports near a coordinate (radius in km, default metric)
curl -q -LSsf "https://YOUR_SERVER/api/v1/nearby?lat=40.64&lon=-73.78&radius=50"

# Bounding-box query
curl -q -LSsf "https://YOUR_SERVER/api/v1/bbox?minLat=40&maxLat=42&minLon=-75&maxLon=-73"

# Bulk dataset (JSON / CSV / GeoJSON)
curl -q -LSsf https://YOUR_SERVER/api/v1/airports.json
curl -q -LSsf https://YOUR_SERVER/api/v1/airports.csv
curl -q -LSsf https://YOUR_SERVER/api/v1/airports.geojson

Unversioned aliases

For client convenience, these unversioned aliases are mounted to the same handlers as the current API version:

  • /api/healthz → /api/v1/server/healthz
  • /api/swagger → /api/v1/server/swagger
  • /api/graphql → /api/v1/server/graphql

FAQ

Do I need an API key?
No. Every endpoint is public.
Where does the data come from?
OurAirports public-domain dataset, embedded into the binary at build time.
How fresh is the data?
Airport data is refreshed each release. GeoIP databases auto-update weekly.
What units does radius use?
Kilometres by default. Pass units=imperial for miles.
